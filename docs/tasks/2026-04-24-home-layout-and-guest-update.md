# Home Layout And Guest Update

## Objective

ホーム画面の情報構成を整理し、カウントダウンとプログラムカードを外したうえで、公演情報と出演者情報を現在の案内内容に合わせて更新する。

## Non-goals

- ヒーローやメッセージ投稿など他セクションの大幅な再設計
- チケット導線やカレンダー連携の仕様変更
- キャストカード全体のデザイン刷新

## Scope

- `src/components/HomeContent.tsx` のセクション並び
- `src/components/EventInfo.tsx` の表示内容とゲスト情報
- `src/components/CastCards.tsx` の出演者カード追加
- 必要な共有コンテンツデータと運用ドキュメント

## Acceptance Criteria

- カウントダウンセクションがホームから消え、その位置に公演情報が表示される
- プログラムカードセクションがホームから消える
- 公演情報に3名のゲスト名が追加される
- `物語を紡ぐ者たち` に `青い鳥 / 南野 高廣` が追加される
- デスクトップとモバイルの両方で、情報量が増えても読みやすさが保たれる

## Verification

- `npm run test`
- `npm run lint`
- `npm run build`
- ホーム画面のデスクトップ表示でセクション順と公演情報の内容を確認
- ホーム画面のモバイル表示で公演情報とキャストカードの折れ方を確認
- カウントダウンとプログラムカードが表示されないことを確認

## Risks and Assumptions

- ゲスト名の表記は添付画像に基づいて反映する
- プログラム概要は `EventInfo` 内の短い章要約を残し、独立したプログラムカードセクションのみ外す
- カウントダウン用コンポーネントファイル自体は残しても、ホームから外れていれば要件を満たす
