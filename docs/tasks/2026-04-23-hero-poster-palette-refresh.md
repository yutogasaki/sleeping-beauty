# Hero Poster Palette Refresh

## Objective

トップのヒーローを提供画像ベースのフルビューポート表示に切り替え、ページ全体の配色をポスターの色味に寄せる。

## Non-goals

- トップ以外のコンテンツ構成や文言の変更
- 新しいセクションやUIパターンの追加
- 情報設計やCTA導線の再設計

## Scope

- `src/components/MainHero.tsx` のヒーロー表示
- `src/app/globals.css` を中心としたグローバル配色トークン
- 旧ブルー/ゴールド前提の残存スタイルの最小調整
- 追加アセット `public/images/sleeping-beauty-hero-poster.png`

## Acceptance Criteria

- トップヒーローが提供ポスターを主役にしたシンプルな全画面表示になる
- 下層コンテンツや主要UI構造は変えない
- 全体配色がポスターと提供パレットに沿った暖色・セージ系へ更新される
- デスクトップとモバイルの両方でヒーロー画像が破綻せず表示される

## Verification

- `npm run test`
- `npm run lint`
- `npm run build`
- ローカルでトップページのデスクトップ表示を確認
- ローカルでトップページのモバイル表示を確認
- 画像差し替え後も下層セクションの可読性が大きく崩れていないことを確認

## Risks and Assumptions

- ポスター画像は横長のため、モバイルでは全面トリミングよりも全体表示優先で扱う
- ヒーロー内の既存コピーはポスターと役割が重複するため、トップはビジュアル主体の表示に寄せる
- 既存コンポーネントの構造は維持し、色味の追従は必要最小限の差分で行う
