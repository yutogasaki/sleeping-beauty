# Task: CI Checks

## Objective

Automate the repo's baseline quality checks so pushes and pull requests run the same verification steps without relying only on local discipline.

## Non-goals

- Deployment automation
- Visual regression infrastructure
- Browser E2E automation

## Scope

- GitHub Actions workflow for `test`, `lint`, and `build`
- Small documentation updates so repo rules match actual automation
- A completion record in `docs/done/`

## Acceptance Criteria

- A GitHub Actions workflow exists in `.github/workflows/`.
- The workflow runs `npm ci`, `npm run test`, `npm run lint`, and `npm run build`.
- The workflow triggers on pushes and pull requests.
- Local verification still passes after the workflow is added.

## Verification

- `npm run test`
- `npm run lint`
- `npm run build`

## Risks and Assumptions

- Keep CI simple and deterministic.
- Match the repo's current Node and npm usage rather than over-abstracting.
