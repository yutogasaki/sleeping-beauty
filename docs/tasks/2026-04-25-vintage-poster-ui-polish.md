# Vintage Poster UI Polish

## Objective

既存の公開トップページの構造、表記、CTA、カード形式を保ったまま、提示画像に近いアンティークなバレエ公演ポスター調のデザインテイストへ寄せる。

## Non-goals

- 画面構成、セクション順、主要コピー、CTAの意味を変更しない
- カードの情報設計やインタラクションを作り替えない
- 新しい決済、認証、データ連携を追加しない

## Scope

- 公開トップページのグローバル配色、背景、装飾、カード、ボタン、モーダルの見た目
- 主要セクション: Hero, Prologue, EventInfo, CastCards, MessagesSection, GiftSection, BehindTheScenes, Footer
- 既存アセットを活用し、新規外部サービスや環境変数は追加しない

## Acceptance Criteria

- 既存UIの表記方式、セクション構成、CTA動作、カード形式が維持されている
- 全体が提示画像のような生成り紙、細い飾り罫、淡いローズ/セージ/ブラウン、植物画のテイストに寄っている
- 「森に灯る光」は既存の暗い森体験を保ちつつ、周囲と馴染む額装パネルとして見える
- デスクトップとモバイルで余白、文字、タップ領域が破綻しない
- モック機能や送信フォームの成功/エラー/disabled 表示が引き続き読める

## Verification

- `npm run test`
- `npm run lint`
- `npm run build`
- ローカル表示でトップページをデスクトップとモバイル幅で確認
- 主要CTA: チケットモーダル、会場/外部リンク、意気込みフォーム、ギフト選択の表示確認

## Risks and Assumptions

- 提示画像は方向性の参照であり、既存UIを完全な一枚絵レイアウトへ作り替えない
- 既存の絵素材を活用し、足りない装飾はCSSの罫線、背景、疑似要素で補う
