# Program Card Refresh

## Objective

添付の配役表を踏まえた短く読みやすいプログラムカード表現へ更新し、ホーム画面上のプログラム紹介を実際の章構成に沿って分かりやすくする。

## Non-goals

- 全配役一覧の掲載や詳細キャストページの追加
- チケット導線や他セクションの情報設計変更
- 演目名や公演基本情報そのものの変更

## Scope

- `src/components/ProgramCarousel.tsx` のプログラム紹介セクション
- `src/components/EventInfo.tsx` のプログラム要約
- 共有文言データの追加
- 必要に応じたコンテンツ運用ドキュメントの追従

## Acceptance Criteria

- プログラムセクションが `Chapter 1 / Chapter 2 / Chapter 3` の3章構成を短い文言で伝える
- `Chapter 1` はバレエ作品、`Chapter 2` は創作作品中心、`Chapter 3` は `眠れる森の美女` として明確に読める
- 公演名、日付、会場を含むカードとして見える
- デスクトップとモバイルの両方でカードと章紹介が読みやすい
- `EventInfo` のプログラム要約も同じ章構成とトーンに揃う

## Verification

- `npm run test`
- `npm run lint`
- `npm run build`
- ローカルでホーム画面のプログラムセクションをデスクトップ表示で確認
- ローカルでホーム画面のプログラムセクションをモバイル表示で確認
- `EventInfo` のプログラム要約と文言の整合を確認

## Risks and Assumptions

- 演目の詳細配役はカードには載せず、章の性格が伝わる短い要約を優先する
- `Chapter 2` は創作作品中心だが `サタネラ` を含むため、文言は「創作作品」を主軸にした総称で扱う
- 既存の横スクロール演出は、短いカード文言との相性を優先して見直す可能性がある
