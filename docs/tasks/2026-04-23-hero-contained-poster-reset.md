# Hero Contained Poster Reset

## Objective

ヒーローポスターは活かしつつ、ページ全体のUIシステムは元のネイビー / 白 / 金の世界観へ戻す。

## Non-goals

- ヒーロー以外の情報設計やセクション構成の変更
- CTAの追加や導線の再設計
- 新しいアニメーションや装飾表現の追加

## Scope

- `src/components/MainHero.tsx` のヒーロー背景構造
- `src/app/globals.css` の配色トークンとヒーロー専用レイヤー
- ヒーロー更新に伴う最小限の補助調整

## Acceptance Criteria

- トップのポスターは `hero` セクション内だけで表示され、他セクションへ配色や画像が漏れない
- ページ全体の基調はダークネイビー、白文字、金アクセントに戻る
- カードや主要UIは半透明ではなく、面として読める状態を保つ
- ヒーロー下端で次セクションと不自然に重ならず、自然につながる
- デスクトップとモバイルの両方でヒーロー画像が破綻しない

## Verification

- `npm run test`
- `npm run lint`
- `npm run build`
- ローカルでトップページのデスクトップ表示を確認
- ローカルでトップページのモバイル表示を確認
- ヒーロー直下で元のページ空気感へ戻ることを確認

## Risks and Assumptions

- 提供ポスターは明るい生成画像なので、desktop / mobile で見え方を分けつつ可読性を保つ必要がある
- 既存コンポーネントの色指定はCSS変数依存が多いため、トークン復元で広範囲に見た目が変わる
- モバイルは全面クロップよりも、暗い背景の上でポスター全体を極力見せる方向を優先する
