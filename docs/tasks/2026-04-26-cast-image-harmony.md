# Cast Image Harmony

## Objective

キャストカード内の個々の画像を、現在のアンティークな紙面・細い飾り罫・夜空の紋章感により自然に馴染ませる。

## Non-goals

- キャスト情報、表示順、カードの裏表インタラクションを変更しない
- 公開トップページ全体の構成やCTAを変更しない
- 画像以外の新しいコンテンツや演出は追加しない

## Scope

- `src/components/CastCards.tsx` のキャスト画像表示
- `src/app/globals.css` のキャスト画像メダリオン用スタイル
- `public/images/cast-*-sage.png` の新規生成画像
- 公開トップページのキャストセクションのみ

## Acceptance Criteria

- 6点のキャスト画像が同じ「古いバレエ絵本のセージ色メダリオン」トーンに見える
- フロリナ王女 / 藤原 彩愛 のカードが追加される
- カラボス画像の写実感と強いコントラストがカード群の中で浮きにくくなる
- 小さいカード表示でも被写体が読みやすく、装飾が主張しすぎない
- 裏面の所属先名は残し、「所属」ラベルだけ表示しない
- 役名、タップ導線、裏面情報、フリップ動作は維持される
- デスクトップとモバイルで画像の切れ方、余白、カード配置が破綻しない

## Verification

- `npm run test`
- `npm run lint`
- `npm run build`
- ローカル表示でキャストセクションをデスクトップ幅とモバイル幅で確認
- フリップ動作が引き続き動くことを確認

## Risks and Assumptions

- 生成画像の細部は完全な制御ができないため、最終判断は実表示で行う
