# Cast Image Harmony

## What Changed

- キャストカード用に、セージグリーン背景の新しい円形メダリオン画像を6点生成しました。
- フロリナ王女 / 藤原 彩愛 のカードを追加しました。
- 各画像は小さいカード表示でも読めるよう、被写体を大きめにして装飾を少なめにしました。
- キャスト画像枠の背景も濃紺からセージ/オリーブ系へ寄せました。
- カード裏面の所属先名は残し、「所属」ラベルだけ削除しました。
- 既存の役名、裏面情報、カードフリップ動作は維持しました。

## Why

- 個々のキャラクター画像を、サイト全体のアンティークな紙面、セージ文字、淡い植物画の雰囲気に馴染ませるため。

## Verification Run

- `npm run test`
- `npm run lint`
- `npm run build`
- Playwrightでキャストセクションをデスクトップ幅とモバイル幅で確認
- Playwrightでモバイル幅のカードフリップ動作を確認

## Residual Risks

- 生成画像の細部は完全な制御ができないため、最終判断は実表示で行います。
- ローカル確認時に `/images/crown.png` の既存 `sizes` 警告が1件出ていますが、今回のキャスト画像変更とは別件です。

## Follow-ups

- さらに統一感を上げる場合は、装飾をさらに減らしたプロンプトで再生成する。
