# Done

Use this folder for short completion records.

## Purpose

Done records help the next person understand:

- what shipped
- why it mattered
- what was verified
- what still needs attention

## Naming

Use:

`YYYY-MM-DD-short-title.md`

Try to match the name of the related task file when possible.

## Rules

- Keep records short and outcome-focused.
- Do not paste long chat histories.
- Do not turn Done into a full changelog.
- Link to the task, ADR, memory entry, or source files when useful.
