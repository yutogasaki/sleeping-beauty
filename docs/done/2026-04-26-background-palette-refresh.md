# Background Palette Refresh

## What Changed

- Replaced the continuous beige page feel with section-level scenic backgrounds.
- Gave the prologue, cast, messages, and closing areas deeper forest, wood, and stage-black treatments.
- Kept event information and flower-gift areas on warmer paper surfaces for readability.

## Why

The public page needed more visual rhythm and stage atmosphere without changing the event content or CTA behavior.

## Verified

- `npm run test`
- `npm run lint`
- `npm run build`
- Desktop and mobile visual checks with Playwright screenshots.
- Confirmed no horizontal overflow on desktop or mobile.

## Still Worth Watching

- Full-page screenshots can show blank animated sections before scroll-triggered content enters view; viewport-by-viewport checks are more representative for this page.
